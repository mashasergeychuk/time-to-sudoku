# time to sudoku: як запустити сайт з оплатою

## Що в папці

- `index.html` — сам лендинг.
- `thanks.html` — сторінка, куди покупець повертається після оплати.
- `logo-flower.svg` — лого.
- `netlify/functions/` — дві маленькі серверні функції: створюють рахунок у plata by mono і перевіряють, чи пройшла оплата.
- `netlify.toml` — налаштування для Netlify.

Нічого з цього не видаляйте і не перейменовуйте.

## 1. Отримати токен mono

1. Підключіть інтернет-еквайринг для ФОП у застосунку monobank.
2. Зайдіть на web.monobank.ua, у розділ інтернет-еквайрингу, і скопіюйте **токен** (X-Token).
3. Для перевірки без справжніх грошей візьміть **тестовий токен** на api.monobank.ua. З ним можна «платити» будь-якою вигаданою карткою.

Токен — це ключ до ваших платежів. Нікому його не пересилайте і не вставляйте в код сайту.

## 2. Викласти сайт на Netlify

Серверні функції потребують деплою з GitHub або через Netlify CLI. Простий перетяг папки на netlify.com/drop може їх не підхопити.

Найпростіший шлях без програмування:

1. Створіть безкоштовний акаунт на github.com.
2. Створіть новий репозиторій (New repository), назвіть його `time-to-sudoku`.
3. Натисніть **uploading an existing file** і перетягніть **вміст** цієї папки (усі файли й папку `netlify`). Натисніть **Commit changes**.
4. На netlify.com: **Add new project → Import an existing project → GitHub** і оберіть репозиторій `time-to-sudoku`. Налаштування збірки не змінюйте, натисніть **Deploy**.

## 3. Вставити токен

На Netlify: **Project configuration → Environment variables → Add a variable**.

- Key: `MONO_TOKEN`
- Value: ваш токен з кроку 1

Після цього зайдіть у **Deploys** і натисніть **Trigger deploy → Deploy project**, щоб сайт підхопив токен.

## 4. Увімкнути листи про замовлення

На Netlify: **Forms**. Має з'явитися форма `order`. Якщо її не видно, увімкніть form detection і знову задеплойте сайт.

Далі **Forms → Form notifications → Add notification → Email notification** і вкажіть свою пошту. Кожне замовлення приходитиме листом: номер замовлення, книжечки, сума, контакти й відділення Нової пошти.

## 5. Перевірити

1. Спершу з **тестовим** токеном оформіть замовлення з оплатою карткою.
2. Має відкритися сторінка оплати mono. Після «оплати» ви повернетеся на сторінку «Оплату отримано».
3. Перевірте, що прийшов лист із замовленням.
4. Замініть `MONO_TOKEN` на бойовий токен і знову зробіть Trigger deploy.

## Як зрозуміти, що замовлення оплачене

У листі є номер замовлення, наприклад `TTS-261014-AB12`. Той самий номер стоїть у призначенні платежу у вашій виписці mono. Якщо платіж з цим номером є, замовлення оплачене.

## Що змінювати самостійно

У `index.html`, у кінці файлу, є блок `НАЛАШТУВАННЯ`: нік в Instagram, ціни, характеристики, книжечки.

Якщо змінюєте ціни, змініть їх **також** у файлі `netlify/functions/create-invoice.mjs` (рядки `PRICE` і `SET_PRICE`). Саме за цими цінами mono виставляє рахунок.
